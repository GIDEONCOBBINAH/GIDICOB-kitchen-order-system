# GIDICOB Kitchen Order System (Standalone GitHub Pages Package)

This repository contains the complete standalone web app for **GIDICOB Kitchen OS** with zero external image dependencies.

## Structure
- `index.html`: Main application entry point (uses Lucide SVGs for icons directly).
- `.nojekyll`: Disables Jekyll build on GitHub Pages so all assets serve seamlessly.
- `README.md`: Project documentation.

## Deploying to GitHub Pages
1. Extract this ZIP archive.
2. Push or upload `index.html`, `.nojekyll`, and `README.md` to your GitHub repository root.
3. Enable GitHub Pages in **Settings -> Pages -> Branch: main -> / (root)**.
